# 统一配置

本目录由 A/B/C 协作维护团队共享的配置。机器相关路径放在本地 tools.env，模型密钥放在本地 .env。

第一周需要确认并记录：

- 验证方式、工具版本、顶层模块、参数、源文件列表与 include 路径。
- 时序用例的时钟、复位、使能和初始化语义。
- 综合脚本、标准单元库版本与校验值、工艺角及适用约束。
- 面积定义和单位、延时获取方式和单位、各用例的延时上限。
- 工具超时、最大迭代次数和模型调用预算。

当前不预设延时上限、面积单位或库文件。C 确认后再提交可执行配置，并在实验记录中引用配置路径与版本。
逻辑深度 ltp 如需记录，应单列指标，不能直接写成纳秒延时。
