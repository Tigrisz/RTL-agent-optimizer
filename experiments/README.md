# 精选实验与复现记录

本地批量输出写入 runs/（已忽略）；将有讨论或报告价值的候选、结果摘要与必要日志整理到此目录。

建议结构：

```text
experiments/<case_id>/<run_id>/
├── candidate.v
├── summary.json
└── notes.md
```

每次记录至少包含：

- 原始用例路径与版本、生成候选时的代码提交、候选编号与采用策略。
- 模型名、提示词版本、生成耗时及可获取的调用消耗，不保存密钥。
- 验证状态、验证方式和日志位置；模拟结果必须标注为 mock。
- 验证通过后的基线/候选面积、延时、单位及约束判断。
- 工具版本、共享配置版本、运行命令和必要日志。
- 结果判断与下一步策略。

尚未验证的指标留空；失败、超时和无收益也应如实记录。不要将某次无收益直接记为生成失败。
当前尚无真实实验结果。
